## Descripción

Este proyecto contiene los archivos de un sitio web relacionado con la ecología industrial. Incluye un documento HTML principal y recursos gráficos utilizados para la presentación visual del proyecto.

**Repositorio:** [Ver Sito Web](https://wh1te-fox.github.io/eco.github.io/)

## Características

- Página web basada en HTML.
- Recursos gráficos para la presentación del proyecto.
- Estructura sencilla y fácil de mantener.
- Posibilidad de publicación mediante GitHub Pages, si está habilitado.
- Código fuente disponible para consulta y modificación.
